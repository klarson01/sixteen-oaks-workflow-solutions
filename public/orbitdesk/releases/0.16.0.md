# OrbitDesk Personal 0.16.0

## Update notifications

OrbitDesk Personal 0.16.0 adds a safe notification-only update channel.

- OrbitDesk checks the official public Sixteen Oaks release manifest no more than once every 24 hours.
- Users can manually check from **About → Check for updates**.
- A newer release can be deferred for seven days or skipped by version.
- OrbitDesk does not silently download, install, or restart itself.
- The private application source repository and GitHub credentials are never exposed to the desktop application.

The public manifest is informational. Production installer downloads will be added after code signing and the trusted release process are complete.
