# OrbitDesk Personal 1.0.0

OrbitDesk Personal 1.0.0 is the completed private/internal release by Sixteen Oaks Workflow Solutions.

## Included capabilities

- Project continuity, pinned projects, search, filtering, and project management
- Tasks, priorities, due dates, completion, reopening, and Today’s Focus
- Daily Intelligence for recommended work, deadlines, meetings, and inbox review
- Save Progress, decisions, blockers, next steps, handoff notes, and Work History
- Google Calendar and Gmail read-only awareness
- Quick Launch, dashboards, skills, applications, websites, files, and folders
- Appearance customization and optional Windows wallpaper backgrounds
- First-run onboarding and reusable setup guide
- Local-first storage, backup, restore, diagnostics, Help, privacy guidance, and troubleshooting
- Public update notifications with visible source and connection history

## Distribution status

This release is complete for private/internal use.

The public installer address is intentionally not published yet. Windows signing and trusted external distribution are deferred until OrbitDesk is offered publicly or OrbitDesk Corporate reaches its first external pilot and the deployment method is selected.

OrbitDesk does not silently download or install updates.
