# OrbitDesk Personal 1.0.1

**Released:** July 31, 2026  
**Channel:** Stable  
**Distribution:** Private/Internal

## Guided Project Update

OrbitDesk Personal 1.0.1 restores the planned end-of-session project handoff workflow.

From Project Detail, select **Create project update** to:

1. Generate a project-specific AI prompt.
2. Copy it into ChatGPT, Claude, or Copilot.
3. Paste the structured response back into OrbitDesk.
4. Review and edit the parsed update.
5. Save the approved handoff into Work History and the current project state.

The structured handoff includes:

- Accomplished work
- Where the project was left
- The next practical action
- Remaining tasks
- Current blocker
- Pending decision

## Save behavior

The accepted workflow:

- Saves accomplished items to Work History.
- Preserves the handoff context.
- Updates the next practical step, blocker, and decision.
- Creates project tasks while skipping duplicates.
- Refreshes Project Detail, Work History, and tasks immediately.
- Uses the existing Personal project and task stores.

## Copy Prompt correction

Installed testing identified and corrected a desktop clipboard issue. **Copy prompt** now confirms success, displays **Copied**, and provides a truthful manual-copy fallback only when Windows blocks automatic copying.

## Edition isolation

The Personal workflow is loaded only by OrbitDesk Personal. OrbitDesk Corporate retains its own isolated guided-update implementation.

## Acceptance

The guided modal, project-specific prompt, clipboard copy, AI response parsing, editable review, and save process passed installed acceptance.

Windows signing and a public installer download remain deferred until external distribution or the first external Corporate pilot.
