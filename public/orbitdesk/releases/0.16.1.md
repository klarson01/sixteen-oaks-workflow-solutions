# OrbitDesk Personal 0.16.1

## Update connection visibility

OrbitDesk now makes its update check fully visible.

The update window shows:

- The official Sixteen Oaks public stable manifest
- The host and full public manifest address
- The last update-check attempt
- The last successful connection
- The current connection state and result
- Controls to copy the address or open the public manifest

The About screen also shows the release source and last connection result.

## Privacy and security

OrbitDesk contacts only the public read-only JSON manifest hosted through `raw.githubusercontent.com`. No GitHub token, private repository access, OrbitDesk workspace information, project data, tasks, Google data, or personal information is sent.

OrbitDesk remains notification-only. It does not silently download, install, restart, or replace the application.
